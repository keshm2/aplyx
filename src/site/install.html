Install aplyx

One command. aplyx drives whichever coding agent you already have: full capability with opencode or Claude Code.

curl -fsSL https://raw.githubusercontent.com/keshm2/aplyx/main/src/scripts/install/install.sh | bash

Installs to ~/aplyx (override with APLYX_HOME). Detects your coding agent, walks you through your profile (kept local-only), and offers the optional desktop app.

irm https://raw.githubusercontent.com/keshm2/aplyx/main/src/scripts/install/install.ps1 | iex

Run in PowerShell. Installs to %USERPROFILE%\aplyx (override with APLYX_HOME).

npm install -g @keshm/aplyx
aplyx

If you'd rather go through npm directly. Same installer runs underneath either way.

Just want the app?

Skip the terminal — download the desktop app directly and it walks you through setup itself. Same app the installer above offers as a step; this just skips straight to it. (The terminal path above still sets up more: the TUI, and your profile ahead of time.)

You need a coding agent

aplyx doesn't work without one: it's the workflow, the agent is the executor. Full capability (browser-automated applies included) with opencode or Claude Code. Codex CLI and GitHub Copilot CLI work too, on a smaller path: API-fed boards only, with browser-only applications routed to your review queue.

What the installer does

  • Detects whichever coding agent(s) you already have installed
  • Walks you through your profile (kept local-only, never uploaded)
  • Creates a data/resumes/ folder for your base resumes
  • Offers Discord status updates and the desktop app, both optional

The browser extension

Submitted to the Chrome Web Store — once it's approved, this section switches to a one-click "Add to Chrome" link. Until then, install it the same way any Manifest V3 extension gets loaded during development:

  1. Clone or download the aplyx repository.
  2. In a terminal, run cd src/extension && npm install && npm run build.
  3. Open chrome://extensions in Chrome, and turn on Developer mode (top right).
  4. Click Load unpacked, and select the src/extension/dist folder.
  5. Start the local bridge: python3 src/scripts/runtime/extension_bridge.py, then run python3 src/scripts/runtime/extension_bridge.py --show-token and paste that token into the extension's Options page.

See the extension page for what it actually does once it's installed.
