## Already Tried / Avoid
- Badge "Pending"/"Applied" overlap: two prior attempts (shortening fade window, then hard-cut opacity) did NOT fix it — root cause was `color-mix(color, transparent)` translucent badge backgrounds letting the layer underneath show through for the entire "on" duration, not a transition-timing issue. Fixed by mixing against solid `#16161d` instead of `transparent`. Don't revisit transition timing for this class of bug — check background opacity first.
- `object-position` on `.mini-peek-desktop img` had zero effect — `width:230%; height:auto` makes the img's own box exactly match scaled content, leaving no size mismatch for object-fit/position to resolve. Fixed via negative `margin-left`/`margin-top` instead (actual positional shift).
- Diagnosing live animation behavior via the Chrome extension tab: this session's automation tab is persistently backgrounded (`document.hidden: true`), and Chrome freezes ALL CSS animations (confirmed for both `background-position` and `transform`) in that state — sampling shows frozen values regardless of which is actually broken. Cannot be used to verify ongoing-animation bugs; only useful for static/one-shot state checks (DOM classes, computed styles at rest, screenshots).
- Root cause of the very first "page renders blank" bug: `IntersectionObserver` callbacks can fail to fire entirely (backgrounded tab confirmed as one trigger); fixed with a 2s `setTimeout` safety net in `site.js` that force-adds `.is-visible` to anything still hidden. This is a permanent, load-bearing fix — do not remove.
